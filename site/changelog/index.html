0.1.0 — first release

The first release of Nook, a fork of Coucou for Windows. Highlights:

  • The island. It sits at the top of the screen, folds to a thin pill, opens on hover or when a session needs you, and rests between beats.
  • Sessions on one page. Claude Code sessions with their state, last message and subagents, and a button that goes to the window each one runs in.
  • Approvals and questions. Permission requests and questions answered from the island, with a real diff for edits. No approval without a click; if nobody answers, Claude Code asks in the terminal.
  • The relay. nook-hook is run by Claude Code on each hook event. It never blocks Claude Code, checks it is talking to Nook (same user, nook.exe, no lower integrity level) and talks only over a named pipe that only the current user can open.
  • Safe hooks. Hooks are installed and removed from Settings with a diff preview, a dated backup and a click.
  • Usage and system. Claude usage limits (5-hour and weekly) and CPU, GPU and RAM in the header.
  • Gullu. Nook’s own buddy, with reactions to the pointer and to session status.
  • The Shelf. To-do, Timer, Reminders, Media, Mirror and Projects widgets.
  • Shortcuts and visibility. Three configurable global shortcuts, auto-hide in full-screen apps, and paging by swipe.
  • Private by design. No telemetry and no network calls.
  • Own art and sounds. Sounds synthesized from plain tones; none of Coucou’s art or sounds.
  • Linux. The same code builds for Linux.

The full list is in the CHANGELOG.md in the repository.

New in v0.1.x (unreleased build)

  • Cursor agent sessions are shown next to Claude Code ones, status only: nothing to approve or answer from the island. Claude sessions wear the sparkle mark and Cursor sessions the cube; the session list has All, Claude Code and Cursor filter chips; Cursor dots on the folded island have a hole.
  • Setup is in Settings, Cursor, Install: a preview of the diff, a dated backup and an explicit click, writing ~/.cursor/hooks.json. Restart Cursor afterwards. It listens only to observational events, never allows, denies or delays anything in Cursor, and its relay always exits immediately. See Cursor and Nook.

Planned

Planned means planned. These are things we intend to do. They are not built yet, and no dates are promised.

  • Code signing of the installer and the programs inside it through the SignPath Foundation’s free programme, once the project qualifies, so the SmartScreen warning fades.

Watch the releases page for new versions, and download the latest from GitHub.
