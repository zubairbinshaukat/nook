How it works

Hooks in, island out. Nothing leaves your PC.

Claude Code already tells hooks what it is doing. Nook listens, locally, and turns that into one calm island.

  1. Claude Code runs a hook

    On each event (a prompt, a tool call, a permission request) Claude Code runs nook-hook, a tiny relay. Hooks are installed from Nook’s settings after a preview and a backup.

  2. The relay hands it to Nook

    It passes the event to the app over a local named pipe, giving Nook 300 ms to answer. If Nook is closed or slow, the relay exits and Claude Code carries on untouched.

  3. The island shows it

    Every session appears at the top of your screen with its state. Approvals and questions can be answered right there. Nothing is ever approved without your click.

Claude Code→nook-hook→local pipe→Nook island

Privacy & trust

Your code stays on your machine.

Nook is a local app with a short list of things it will not do. All of it is in the open-source code, so you can check.

No network, no telemetry

No network calls, no analytics, no account. Events travel only from Claude Code to Nook, on your own PC.

Never without a click

Nook never approves anything for you. If nobody answers in time, Claude Code simply asks in the terminal as usual.

Never blocks Claude Code

The relay gives Nook 300 ms and exits cleanly if it is closed, slow or crashed.

Safe settings changes

Nook shows the exact diff and takes a dated backup before it touches ~/.claude/settings.json. Only after your click.

This site sets no cookies and uses no analytics, so there is no cookie banner. Read the privacy page.

Install

Up and running in three steps.

Windows 10 or 11. WebView2 ships with both. Free and open source (MIT).

  1. Download the installer

    Get Nook-Windows-0.1.0-setup.exe from the latest release on GitHub.

    Download for Windows

  2. Run it, then confirm once

    The installer is not code-signed yet, so SmartScreen may say “Windows protected your PC”. Choose More info, then Run anyway.

  3. Install the hooks

    Open Settings → Claude Code → Install hooks…, review the preview, click. Start a Claude Code session and watch the island.

Check the download (optional, recommended)

Compare the hash with the one for the installer in SHA256SUMS.txt on the release page.

Get-FileHash .\Nook-Windows-0.1.0-setup.exe -Algorithm SHA256

Why the warning? SmartScreen does not know new, unsigned programs yet. Nook is open source, so you can read the code or build it yourself. If an antivirus flags nook-hook.exe, it is the kind of false positive small unsigned tools get. See the troubleshooting guide and the full install guide.

FAQ

Questions, answered plainly.

Is Nook free and safe?

Nook is free and open source (MIT-licensed code), so anyone can read exactly what it does. It runs 100% locally: no network calls, no telemetry and no account.

Does Nook send my code or prompts anywhere?

No. Events go from Claude Code's hooks to a small local relay and then to Nook, all on your own computer. Nook makes no network calls and has no telemetry.

Will Nook approve things for me or get in Claude Code's way?

No. Nook never approves anything without your click, and it never blocks Claude Code. The relay gives the app 300 ms to pick up; if Nook is closed, slow or crashed, it exits and Claude Code asks in the terminal as usual.

Does Nook change my Claude Code settings?

Only when you ask. Installing hooks shows the exact diff of what will change in ~/.claude/settings.json and takes a dated backup first. Nothing is written until you click, hooks from other tools are left alone, and Uninstall hooks removes only Nook's entries the same way.

Why does Windows show "Windows protected your PC"?

The installer is not code-signed yet, and SmartScreen does not know new, unsigned programs. If you downloaded it from the official GitHub release, choose More info, then Run anyway. You can verify the download with Get-FileHash .\Nook-Windows-0.1.0-setup.exe -Algorithm SHA256 and compare it with SHA256SUMS.txt, or build Nook from source.

My antivirus flagged nook-hook.exe. What now?

That is a typical false positive for small, unsigned programs that other programs start often. You can report it to Microsoft at https://www.microsoft.com/wdsi/filesubmission as "Software developer" and "Incorrectly detected", or build Nook from source.

Which systems and Claude Code setups does it work with?

Nook 0.1.0 is built for Windows 10 and 11. It follows Claude Code through Claude Code's hooks, so sessions appear whether you start Claude Code in a terminal window or in the integrated terminal of an editor such as VS Code.

Does Nook support Cursor or other agents?

Yes. Nook shows Cursor agent sessions next to Claude Code ones, status only: you can see what a Cursor agent is doing, but you cannot approve or answer from the island. Turn it on in Settings, Cursor, Install (preview, dated backup, click). New in v0.1.x (unreleased build). Claude Code running inside Cursor's terminal works as a normal Claude Code session.

Does it slow down my PC?

Nook is a small desktop app that reacts to events from Claude Code's hooks. It also shows CPU, GPU and RAM in the island, so you can check its footprint on your own machine.
