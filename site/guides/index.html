Nook guides

Install Nook, connect it to Claude Code and fix the things that go wrong.

Last updated 2026-10-08 · Nook 0.2.2 · Was this helpful? Report a problem

Nook is a free, open-source Dynamic Island for Claude Code agents on Windows. These guides cover everything from the first download to a tricky bug report. Each guide is short, written for the 0.2.2 release and kept in plain language.

Which guide do you need?

  • New to Nook? Start with installing Nook on Windows, then the first-run guide.
  • Curious how Nook sees your sessions, or worried about your settings? Read how Nook talks to Claude Code.
  • Something not working? Go to troubleshooting.
  • Quick questions about privacy, safety or signing? See the FAQ and the privacy policy.
  • Using Cursor? See Cursor and Nook. Using Codex, or want to reply from the island? See Codex and Nook.

Nook is free and open source. If a guide is wrong or missing something, report a problem.
