Preview controls

The Shelf with fake data (plans/tabs-plan.md): six small widgets that work where they stand, each with an expanded view of the same state. Use a card's controls in place; tap its header, its empty area or the corner icon to expand it. Drag or two-finger swipe to scroll the row (a drag never taps); hold a card's header for 350 ms, then drag, to reorder. Back from an expanded view: Esc, swipe right, or the back pill. Tabs: a click, ← →, or a swipe past the row's end.

Jump to

From the shelf, a jump to a widget is the same morph as a tap on its card; "Shelf" from an expanded view is the same morph back. From anywhere else it is the island's ordinary change of view.

Use a control in place

Better done on the cards themselves: tick a box, type in "Add an item…" and press Enter, press play, start the timer, add a reminder, press "Code" on a project. Then expand the card: it is the same state, and a running timer keeps running in both sizes. These three buttons call the same functions from outside, so it can be seen with a widget expanded too.

Agent alert

The card takes over at once, over any widget (the camera stops). Answering it, or "Back to …", returns to where you were with the widget's state kept.

Cooldown

Wheel events with |deltaX| > |deltaY| scroll the row first; at its end they add up, and past the threshold one tab switches, then deltas are ignored for the cooldown. A wheel event never presses anything. No trackpad? Shift + mouse wheel sends deltaX too, or drag the row.
